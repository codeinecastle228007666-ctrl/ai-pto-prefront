## Расхождения

### Auth / сессия

| Docs (этап 1) | Код |
|---------------|-----|
| Cookie `ai_pto_session`, HttpOnly; JWT в localStorage не использовать | Bearer JWT: `accessToken` / `refreshToken` в `localStorage` |
| Login: только email + password, 401 → «Неверный email или пароль» | `LoginForm.tsx` пишет токены; текст ошибки шире |
| Нет refresh в MVP-контракте этапа 1 | `POST /auth/refresh` в `endpoints.ts` и interceptor в `client.ts` |
| Пользователь из `GET /auth/me` в React Query | Частично: Zustand + persist токенов; `/auth/me` упоминается, но сессия завязана на токены |

Файлы: `src/shared/api/client.ts`, `src/features/auth/ui/LoginForm.tsx`, `src/features/auth/model/authStore.ts`, `src/features/auth/api/authApi.ts`.

### Маршруты

| Docs | Код |
|------|-----|
| `/` — обзор | `/` → redirect на `/dashboard`; обзор на `/dashboard` |
| `/objects/new` — страница создания | Маршрута нет; создание через Sheet `ObjectForm` на `/objects` |
| `/objects/:id/edit` | Есть (`ObjectEditPage`) + дублирующий edit через Sheet на списке |
| Пункты «Документы / Замечания / Комплектность / Отчёты» не показывать | В сайдбаре есть, `disabled: true` |
| Профиль — только просмотр | Есть формы профиля и смены пароля (`ProfileForm`, `PasswordForm`) |

Файлы: `src/app/router.tsx`, `src/widgets/sidebar/ui/Sidebar.tsx`, `src/pages/profile/*`, `src/pages/objects/ui/ObjectsPage.tsx`.

### Объекты / API

| Docs | Код |
|------|-----|
| Колонки: название, **код**, тип, адрес, заказчик, подрядчик, **статус** | Код вложен в ячейку названия; плюс колонки **готовность**, **последняя проверка**, actions |
| `includeArchived=true` + переключатель «Показать архив» | Отдельного переключателя нет; фильтр статуса включает `archived` |
| `POST /objects/{id}/status` с разрешёнными переходами | Вызова status API нет; статус в форме create/edit (`ObjectFormFields`) |
| `POST /objects/{id}/archive`, только `owner` видит кнопку | `DELETE /objects/{id}` (`objectsApi.archive`); кнопка архива **без проверки роли** |
| Справочник `GET /counterparties` | `GET /organizations` (`ENDPOINTS.catalogs.organizations`) |
| Карточка: кнопки «В работу / Пауза / Завершить» | Нет; только Архивировать + Редактировать |
| Архивный объект — только чтение, edit недоступен | Edit/Sheet не блокируются явно по `archived` (кнопка архива disabled, edit доступен) |
| После create — переход на карточку | Create через Sheet остаётся на списке (`ObjectsPage.handleSubmit`) |

Файлы: `src/features/objects/api/objectsApi.ts`, `src/shared/api/endpoints.ts`, `src/features/objects/model/useColumns.tsx`, `src/pages/object-detail/ui/ObjectDetailPage.tsx`.
